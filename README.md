# Automatic School Bell System - Official Website

This folder contains the complete, modern landing page website for the **Automatic School Bell System**.

## How to Publish on GitHub Pages (Takes 1 Minute):

1. Go to [GitHub](https://github.com) and create a new public repository (e.g., named `school-bell-system`).
2. Upload all files from this `SchoolBell_Website` folder into the repository root:
   - `index.html`
   - `README.md`
   - `https://github.com/rrajak7499/school-bell-system/releases/download/school_alarm_system/SchoolBell_Installer.exe` (Make sure the `downloads` folder containing the setup `.exe` is uploaded as well).
3. In your GitHub repository, go to **Settings** -> **Pages**.
4. Under **Build and deployment**, set **Source** to `Deploy from a branch`, and select `main` (or `master`) branch `/ (root)`. Click **Save**.
5. Within 60 seconds, GitHub will give you your live website URL (e.g. `https://yourusername.github.io/school-bell-system`) where users can visit to read about the software and download `SchoolBell_Setup.exe` directly!
